# Security Policy

## Reporting a vulnerability

Please report security issues privately to Kamraan.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/kahraman-aydin/kamraan-open-meteo-sdk/issues

## Scope

This policy applies to the generated Kamraan SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Open-Meteo Weather Forecast public API, generated by
Kamraan. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
